OZURO LAUNCHER — BÊTA 0.4.54-beta.1

Fermer l’ancien launcher puis ouvrir Ozuro-Launcher-0.4.54-beta.1.exe sur Windows 10/11 x64. Les jeux, sources et préférences sont conservés. Les bêta récentes détectent aussi cette version par leur mécanisme de mise à jour au démarrage.

TÉLÉCHARGEMENTS TORRENT

Tous les jeux torrent utilisent le moteur intégré : qBittorrent n’est pas nécessaire chez les joueurs. Les annonces HTTP(S) privées passent automatiquement en IPv4. Le propriétaire doit maintenir une source joignable.

La communication avec le moteur local utilise une connexion IPv4 directe. Si elle reste sans réponse après les tentatives de lecture, Ozuro confirme l’arrêt de l’ancien processus puis tente une seule reprise avec le même cache et les mêmes modes. Une pause demandée par le joueur annule cette reprise. Une panne persistante conserve les fichiers et affiche une erreur ; aucune boucle de relance infinie n’est ajoutée.

Les grandes sélections de modes demandent moins souvent le détail de chaque fichier. Les informations légères de vitesse et de connexion restent actualisées. Un deuxième moteur du launcher ne peut pas ouvrir le même cache actif dans son processus.

Le secours HTTPS est disponible seulement si le propriétaire configure un miroir publié, lié à l’empreinte du torrent. Aucun miroir réel n’est activé dans cette publication.

PARTAGE ET LIMITES

Ozuro Partage continue de partager les caches vérifiés après fermeture du launcher, avec un envoi illimité par défaut pour les nouveaux profils. Les choix existants sont conservés. Le PC doit rester allumé et connecté ; l’icône près de l’horloge permet d’arrêter le partage.

VALIDATION

221 tests automatisés réussis, 0 échec et 1 test HTTPS public optionnel ignoré. Les essais incluent un torrent synthétique de 2 102 fichiers, une panne du moteur, la reprise des morceaux reçus, les modes non sélectionnés, la pause et l’absence de doubles moteurs. 286 contrôles d’interface et le remplacement/redémarrage du vrai EXE portable sont vérifiés. Ces essais ne constituent pas une installation complète et un lancement de chacun des 13 vrais jeux.

L’EXE n’est pas signé Authenticode. Vérifier son empreinte dans SHA256SUMS.txt. Les détails figurent dans SECURITE.md.
