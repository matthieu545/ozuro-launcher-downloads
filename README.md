## Utiliser

1. Ouvrir le launcher sur Windows 10 ou 11, en 64 bits.
2. Sélectionner un jeu et les modes souhaités.
3. Choisir son dossier d’installation, puis démarrer le téléchargement.
4. Une fois l’installation terminée, choisir le mode et cliquer sur Jouer.

Les téléchargements dépendent de la disponibilité des sources et des joueurs qui partagent les fichiers. Les prérequis Microsoft manquants sont détectés par le launcher ; Windows peut demander une autorisation pour les installer.

## Version 0.4.33-beta.1

- Badge **BÊTA** dans Ozuro Launcher.
- 12 fonds de jeux intégrés, avec changement automatique selon le Call of Duty sélectionné.
- Identité bleu, blanc, rouge conservée.
- Bibliothèque et réglages des versions FR Launcher conservés.

Pour remplacer une ancienne version, fermer l’ancien launcher avant d’ouvrir le nouveau. Les préférences restent dans le dossier historique `%APPDATA%\FR Launcher`.

## Vérifier le fichier

L’empreinte SHA-256 du fichier est fournie dans [SHA256SUMS.txt](SHA256SUMS.txt) et avec la release.

## À propos de ce dépôt

Ce dépôt public sert uniquement à distribuer l’application. Le dépôt de développement est privé. Les jeux, sauvegardes, configuration du tracker et catalogue opérationnel ne sont pas hébergés comme fichiers sources ici.

Le launcher est portable et n’est pas signé numériquement. Un utilisateur disposant de l’EXE peut en extraire les sources de téléchargement ; ce partage ne fournit pas une authentification individuelle.
